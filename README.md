 Minecraft Básico en 3D con Ursina

Este es un pequeño experimento que hice en Python usando la librería [Ursina](https://www.ursinaengine.org/). Crea un mundo básico estilo Minecraft, donde podés colocar y eliminar bloques.

> Proyecto hecho en para probar gráficos 3D.

## Controles

- **WASD**: Moverse
- **Click izquierdo**: Destruir bloque
- **Click derecho**: Colocar bloque

## Requisitos

- Python 3.8 o superior
- [Ursina Engine](https://pypi.org/project/ursina/)

Para instalar Ursina:

pip install ursina
